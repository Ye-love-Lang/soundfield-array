# 可复用提示词

## 软硬件划分
输入器件型号、采样率、通道数、数据位宽、时钟、资源预算、网络接口和延迟目标。提示：请给出数据流及接口契约，把需要确定时序的任务与可异步迭代的任务分开；估计乘加、存储和更新频率；列出尚无证据的假设。输出须包括PL/PS/上位机分工、时钟域与缓冲边界。验证时对照实际RTL、驱动与资源报告，不用模型估计替代结果。

## 失败捕获诊断
输入本轮声源或激励确认、采集代次、块偏移/长度/CRC、所有门限统计和上一有效参数。提示：先判断数据是否属于声称的场景，再求各门限通过集合的交集；区分几何、路径和通道本体偏差；给出最小下一步，禁止只为通过而放宽门限。若证据不足，指出缺什么，勿推断硬件损坏。

## 交付总结
输入本轮变更、源码哈希、构建结果、板端读回、受控输出与用户反馈。提示：分开记录已编码、已构建、已下载、已实测；每一性能数字绑定版本、输入、统计口径和基线；给出可复现入口及未完成项。缺少原始单麦基线时，不把两指向输出比写成单麦SIR收益。
