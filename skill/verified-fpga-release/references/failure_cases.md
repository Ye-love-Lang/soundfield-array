# 失败和观察

1. JTAG暂停读音频使FIFO积压。触发：采样前后溢出计数增加且CPU被暂停。排查：核对暂停时长和上下文，改用正常主循环冻结缓冲与分块读取。验证：0.20.2六段32768样本有效、CRC一致、计数在窗口内不增长。边界：仅覆盖所测窗口。
2. 标定笼统提示相干不足。触发：提交频点不足。排查：检查实际播放，再分别统计能量、相干、幅度、相位以及交集，独立复测。历史一度没有播放，26cm近场与高度也引入误差。不得直接把房间路径用于全局本体校准。局部路径需独立训练/验证，当前现场收益未验收。
3. 新FIR含非有限值。触发：设计失败或NaN。排查：DC端点、输入有限性、逐频约束、提交状态；候选无效保留最后有效银行，硬件故障仍报告。已有故障注入回归；不代表所有瞬态根因已独立复现。
4. 生成BOOT或JTAG启动不证明冷启动。按镜像写入校验、真实断电切启动模式、只读版本查询三阶段确认；查询脚本不应初始化PS或重新下载。RAM参数持久化须另实现。
5. 文件CRC相同不证明源数据可信。历史Flash导出全零，虽传输CRC一致仍未独立证明原存储内容，不能当作可恢复镜像。将传输完整性、来源可信度和功能有效性分别记录。
