# FIR候选硬件接口

未替换正式工程；候选mic_filter_axi.v保留旧寄存器、相关快照、DAS、滤波/增益/FIFO，新增array_fir.v。复位默认FIR关闭；未完整上传/提交不得启用。FIR输出与原DAS输出在滤波/增益前选择，后级峰值保护保留。

| 偏移 | 功能 |
|---|---|
| 0x90 | 12位上传索引0..4095，通道优先、每通道512抽头 |
| 0x94 | 写入20位二进制补码Q18系数，索引自动增加并在4095后回0；读为最后上传值，非RAM校验读口 |
| 0x98 | bit0请求使能，bit1提交脉冲；写2请求回退DAS |
| 0x9C | 实际状态bit0启用、bit1活动bank、bit2后台bank完整、bit3正在计算 |
| 0xA0 | FIR1签名0x46495231 |
| 0xA4 | 输入超过处理能力时的丢帧计数 |
| 0xA8 | 上传顺序/未完成提交/待切换bank被写等配置错误计数 |
| 0xAC | FIR的16位输出饱和计数 |

推荐事务：索引写0，顺序写4096个系数，检查ready及错误计数，再写控制3；下一次接受的PCM帧开始使用整套新bank。不能一边覆盖待切换bank一边提交；核心会拒绝该写入。正常后台上传不会修改正在使用的bank。每次更新必须完整上传，禁用可不上传。PS需轮询实际状态，不能把请求使能读回当成实际已切换。

当前实现为八路并行MAC、同步BRAM读、Q18系数、48位累加，正向半LSB舍入后饱和到S16；历史未填满的位置按零处理。计算耗时518个100MHz时钟（约5.18us），与系数设计共同延时256音频样本（约5.33ms）不是同一概念。单独核心15DSP/12BRAM36等效，综合时序估计满足10ns，仍需整机布线检查。

已验证逐样本整数卷积1300个输出、后台上传、原子提交、正负饱和、过载隔离/复位；系统测试验证单输出、FIR/DAS选择、旧AXI与40次相关快照回归。日志及哈希见rtl_verification.json。

仍待实现/验证：PS实时生成系数和可靠干扰轨迹管理，系数更新平滑过渡、DAS/FIR时延差处理、去直流与定点余量联合验证、实际房间抑制。帧间原子切换只保证不混用系数与不重复输出，不能直接声称听感无点击音。FIR内部饱和是诊断与防绕回，不等于已解决高增益炸麦或外放声反馈。
